# FeedbackCtrlApp


MATLAB-based research applications for processing proton-transfer-reaction time-of-flight mass spectrometry (PTR-ToF-MS) measurements, calibration, and monitoring of volatile compound production in bioprocesses.


## Overview

The project is intended to support workflows including:

* Peristaltic feeding pump calibration
* Analysis of internal calibration of calibration gas and estimation of instrument sensitivity.
* Analysis of external calibration  
* Background correction and quantification of volatile compounds.
* Endpoint quantification of volatile compounds 
* Real-time monitoring and feedback control of bioprocess using PTR-ToF-MS data. 

Actual capabilities depend on the included application versions and experimental configuration. 

Requirements
* MATLAB: 2024b or 2025a
* Required toolboxes: MATLAB Industrial communication toolbox
* Supported operating systems: **N/A**
* Supported input data format(s): **HDF5 layout**
* External calibration data are attached and available at https://doi.org/10.5281/zenodo.21398235.


## Installation
1. Install a compatible MATLAB release and the required MATLAB Industrial communication toolbox.
2. Download the tagged release or clone this repository.
3. Install the relevant MATLAB toolbox (.mltbx) appllication using MATLAB.
4. Test the application using the provided example dataset before analysing experimental data.
